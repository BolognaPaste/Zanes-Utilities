Game library

Add games

Pick your Steam and Epic folders once and the library finds your installed games from then on, re-checking them every time you open this page. Nothing is uploaded; files are read in your browser.

A web page can only read folders you choose, so the first time you will be asked to pick each one. Steam: C:\Program Files (x86)\Steam\steamapps (or your Steam folder). Epic: C:\ProgramData\Epic\EpicGamesLauncher\Data\Manifests. Your browser then remembers them (Chrome or Edge; it may ask permission again after a restart). If you keep games on more than one drive, use "Add another Steam folder" for each library. Play starts a game through Steam or the Epic Games Launcher, which must be installed and signed in.

Other games: add a game yourself by choosing its .exe file (you can pick several at once). Nothing is scanned or re-checked; the library only lists the files you add. A web page cannot start a program, so Play gives you a small launcher (.bat) to open.

Choose files manually instead

In the file picker, open the folder and press Ctrl+A to select every file. Steam and Epic do not let web pages sign in to your account, so only games installed on this computer are listed. Play starts a game through Steam or the Epic Games Launcher, which must be installed and signed in; your browser may ask for permission the first time. If you keep games on more than one drive, load each Steam library's steamapps folder in turn.

Double-click a game to play it. Right-click for more options. Steam games show their official artwork automatically. The Game info menu's "Fetch game info" looks up cover art, genres, developer and release date for every game (including Epic) using a free RAWG API key.

File shredder

Permanently destroys files and folders by overwriting them 5 times before deleting them. Shredded items skip the Recycle Bin and cannot be recovered.

The file shredder only works in the Zane's Utilities desktop app on Windows.

How it works and its limits

Each file is overwritten with zeros, then ones, then random data, then an alternating bit pattern, then random data again. Its name is scrambled and it is deleted. Folders are shredded file by file and then removed. Windows folders, drive roots and your user profile folder cannot be shredded.

Overwriting cannot reach every copy. On SSDs, wear leveling can leave old data in cells the app cannot address, and cloud-synced folders, backups, File History and shadow copies keep their own copies. For SSDs, full-disk encryption (BitLocker) is the reliable protection.

Encrypted vault

Keep private files inside one encrypted container file. Both the contents and the file names are encrypted with AES-256, using a key made from your password. There is no password recovery: if you forget it, nobody can open the files.

The encrypted vault only works in the Zane's Utilities desktop app.

How it works and its limits

Your password is turned into a key with scrypt, which is deliberately slow and memory-hungry (about a second and 256 MB per guess) to make guessing hard. That key unlocks a random master key stored in the vault, and files are encrypted in 1 MB blocks with AES-256-GCM. Every block is authenticated, so any change to the vault file is detected instead of silently producing bad data. File names, sizes and dates are inside the encrypted index.

What it cannot hide: anyone holding the file can see that it is a vault, its total size, and roughly how much is in it. The encryption is only as strong as the password, so use a long passphrase. While the vault is unlocked its key is in memory; it locks after 10 idle minutes or when you press Lock now. Malware or a keylogger on this PC can defeat any encryption.

Adding files leaves your originals in place, and extracted files are ordinary unprotected copies, so use the File shredder on those when you are done. Changing the password re-wraps the master key but does not re-encrypt the files, so an old copy of the vault can still be opened with the old password. Removing files and changing the password rewrite the vault, which needs free disk space about the size of the vault. Keep a backup copy of the vault file somewhere safe.

Driver updater

Checks Windows Update for newer, Microsoft-signed drivers for the hardware in this PC, then installs the ones you pick. Files come from Microsoft, not from this app.

The driver updater only works in the Zane's Utilities desktop app on Windows.

Installed drivers

Drivers from the manufacturers

Windows Update does not carry every driver, and manufacturers often publish newer ones first. This asks NVIDIA, AMD and Intel directly which graphics, Wi-Fi, Bluetooth and chipset drivers are newest and compares them with what is installed. NVIDIA installers can be downloaded here, and are only started after their NVIDIA digital signature checks out; everything else opens the manufacturer's page. Makers like Realtek publish no version feed, so those devices are listed with a link to your PC maker's driver page.
