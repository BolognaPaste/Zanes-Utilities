The file shredder only works in the Zane's Utilities desktop app on Windows.

Shred files for good

Permanently destroys files and folders by overwriting them 5 times before deleting them. Shredded items skip the Recycle Bin and cannot be recovered.

How it works and its limits

Each file is overwritten with zeros, then ones, then random data, then an alternating bit pattern, then random data again. Its name is scrambled and it is deleted. Folders are shredded file by file and then removed. Windows folders, drive roots and your user profile folder cannot be shredded.

Overwriting cannot reach every copy. On SSDs, wear leveling can leave old data in cells the app cannot address, and cloud-synced folders, backups, File History and shadow copies keep their own copies. For SSDs, full-disk encryption (BitLocker) is the reliable protection.

Servers this app trusts

Servers whose fingerprint you confirmed. If one changes without a reason, the app refuses to connect. Forget a server only if you know why its identity changed, for example because it was reinstalled.

Tips and limits

Ctrl+C copies when text is selected and otherwise interrupts the running program. Ctrl+V or Ctrl+Shift+V pastes. Up to 6 connections can be open at once, each in its own tab, and they close when you close the app.

Sign-in works with a password or a private key file (OpenSSH format). Two-step codes and repeated password questions from the server appear in a box over the terminal. SSH agents and port forwarding are not included.

File transfer (SFTP): once connected, press Files above the terminal to browse the server, then upload or download files and whole folders. It uses the same sign-in and the same checked server identity. Nothing on this PC is ever overwritten (a copy becomes “name (1)”), replacing or deleting on the server always asks first, and shortcuts (symbolic links) inside folders are skipped. Only empty folders can be deleted. The server must have its SFTP service turned on, which is the default on most.

Windows tweaks

Games on the right graphics chip

PCs with two graphics chips (most gaming laptops) sometimes run games on the weak one. Choose a game's .exe and Windows will use the high-performance GPU for it. This is the same setting as Settings → System → Display → Graphics.

Other things worth checking

    The rating compares your graphics card, processor and memory against typical gaming hardware. It is a guide, not a benchmark: games differ, so adjust from these starting points. Tweaks only change your own Windows settings, and Undo restores what they were before.

    Setting up the phone

    1. On the phone, open Settings, About phone, and tap Build number 7 times to turn on Developer options.
    

    2. Open Settings, System, Developer options and turn on USB debugging. Some brands (Xiaomi, for example) also have a separate "USB debugging (Security settings)" switch that lets a mouse and keyboard control the phone.
    

    3. Plug the phone in with a cable that carries data, not a charge-only cable. If the phone asks for a USB mode, pick File transfer. Tap Allow on the "Allow USB debugging?" prompt and tick Always allow.
    

    Some apps, such as banking apps and video services, block screen capture and show a black screen in scrcpy. Screenshots and recordings made here are saved in your Downloads\ZanesUtilities folder.
