Game Crash Analyzer

Drop in crash logs (.txt, .log, .xml) or Windows minidumps (.dmp). You get a ranked list of likely causes and what to try. Files are read in your browser and never uploaded.

This is pattern matching, not a full debugger. For deep analysis of a dump, open it in WinDbg or Visual Studio with the game's symbols.

Add games

Pick your Steam and Epic folders once and the library finds your installed games from then on, re-checking them every time you open this page. Nothing is uploaded; files are read in your browser.

A web page can only read folders you choose, so the first time you will be asked to pick each one. Steam: C:\Program Files (x86)\Steam\steamapps (or your Steam folder). Epic: C:\ProgramData\Epic\EpicGamesLauncher\Data\Manifests. Your browser then remembers them (Chrome or Edge; it may ask permission again after a restart). If you keep games on more than one drive, use "Add another Steam folder" for each library. Play starts a game through Steam or the Epic Games Launcher, which must be installed and signed in.

Other games: add a game yourself by choosing its .exe file (you can pick several at once). Nothing is scanned or re-checked; the library only lists the files you add. A web page cannot start a program, so Play gives you a small launcher (.bat) to open.

Choose files manually instead

Play starts a game through Steam or the Epic Games Launcher, which must be installed and signed in; your browser may ask for permission the first time. If you keep games on more than one drive, load each Steam library's steamapps folder in turn.

File shredder

Permanently destroys files and folders by overwriting them 5 times before deleting them. Shredded items skip the Recycle Bin and cannot be recovered.

The file shredder only works in the Zane's Utilities desktop app on Windows.

How it works and its limits

Each file is overwritten with zeros, then ones, then random data, then an alternating bit pattern, then random data again. Its name is scrambled and it is deleted. Folders are shredded file by file and then removed. Windows folders, drive roots and your user profile folder cannot be shredded.

Overwriting cannot reach every copy. On SSDs, wear leveling can leave old data in cells the app cannot address, and cloud-synced folders, backups, File History and shadow copies keep their own copies. For SSDs, full-disk encryption (BitLocker) is the reliable protection.

Setting up the phone

1. On the phone open Settings, About phone, and tap Build number 7 times to turn on Developer options.


2. Open Settings, System, Developer options and turn on USB debugging. Some brands (Xiaomi, for example) also have a separate "USB debugging (Security settings)" switch that lets a mouse and keyboard control the phone.


3. Plug the phone in with a cable that carries data, not a charge-only cable. If the phone asks for a USB mode, pick File transfer. Tap Allow on the "Allow USB debugging?" prompt and tick Always allow.


Some apps, such as banking apps and video services, block screen capture and show a black screen in scrcpy. Screenshots and recordings made here are saved in your Downloads\ZanesUtilities folder.

Drivers from the manufacturers


Windows Update does not carry every driver, and manufacturers often publish newer ones first. This asks NVIDIA, AMD and Intel directly which graphics, Wi-Fi, Bluetooth and chipset drivers are newest and compares them with what is installed. NVIDIA installers can be downloaded here, and are only started after their NVIDIA digital signature checks out; everything else opens the manufacturer's page. Makers like Realtek publish no version feed, so those devices are listed with a link to your PC maker's driver page.
